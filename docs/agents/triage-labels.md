# Triage Labels

Le skill parlano in termini di cinque ruoli canonici di triage. Questo file mappa quei ruoli alle stringhe effettivamente usate nel tracker di questo repo.

| Label in mattpocock/skills | Label nel nostro tracker | Significato                                     |
| -------------------------- | ------------------------ | ----------------------------------------------- |
| `needs-triage`             | `needs-triage`           | Il maintainer deve valutare questa issue        |
| `needs-info`               | `needs-info`             | In attesa di maggiori informazioni dal reporter |
| `ready-for-agent`          | `ready-for-agent`        | Completamente specificata, pronta per un agente |
| `ready-for-human`          | `ready-for-human`        | Richiede implementazione umana                  |
| `wontfix`                  | `wontfix`                | Non verrà gestita                               |

Con il tracker Markdown locale le label sono la stringa nella riga `Status:` del file issue, non un campo separato.

Quando una skill menziona un ruolo (es. "applica la label di triage pronta per agente"), usa la stringa corrispondente da questa tabella.

Modifica la colonna "Label nel nostro tracker" per allinearla al vocabolario che usi davvero.
