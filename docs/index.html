Ingegneria Nativa

Architettura a zero compromessi per macOS

Nessun browser incorporato, nessuna telemetria di terze parti. Ogni componente sfrutta i framework di sistema più veloci disponibili su Apple Silicon.

Cattura Istantanea con Accessibility AX

Si collega all'albero AXUIElement del sistema operativo. Non serve copiare e incollare testo: basta selezionare qualsiasi paragrafo in Safari, Apple Books, Anteprima o Microsoft Word e premere la scorciatoia globale configurata.

Apple Vision OCR Offline

Per i documenti scansionati, i PDF protetti o il testo bloccato all'interno di grafici e presentazioni, Lettore scatta un'acquisizione mirata dell'area e la trasforma in testo leggibile usando i modelli di visione neurale integrati in macOS.

Normalizzatore Intelligente per l'Italiano

Espande in automatico abbreviazioni frequenti ("Dott.", "Ing.", "Sig.ra", "pagg."), date formattate, valute ("150€" in "centocinquanta euro") e URL, per garantire una dizione fonetica naturale e corretta durante la sintesi.

Pipeline Audio Gapless

La riproduzione non attende che l'intero documento sia sintetizzato: genera e accoda i frammenti di frase (chunk) man mano che procedi. Il metering nativo a 20 Hz anima la forma d'onda senza pesare sulla GPU o sulla batteria.

Accessibilità Universale

Costruito per chi legge con le orecchie

Lettore è nato con un obiettivo chiaro: permettere a chi affronta affaticamento visivo, dislessia o difficoltà di concentrazione di fruire di qualunque testo sullo schermo con la stessa naturalezza di un podcast.

  • Navigazione da tastiera senza mouse: scorciatoie globali personalizzabili per avviare, mettere in pausa e scorrere i blocchi senza mai togliere le mani dalla tastiera.
  • Nessun contrasto slavato: l'evidenziatore di lettura usa colori scelti per superare i requisiti WCAG AA su sfondi scuri e chiari.
  • Finestre accessorie senza furto di focus: la pillola fluttuante non toglie il cursore dall'editor di testo o dal documento su cui stai lavorando.

Compilazione con Swift Package Manager

Clona la repository ed esegui il target nativo con un singolo comando:

Terminale macOS (Zsh) 
git clone https://github.com/P3TERexe/lettore-native.git
cd lettore-native

# 1. Avvia il backend locale in una finestra
cd backend && python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt && python main.py

# 2. In un altro terminale compila ed esegui l'app nativa
swift run LettoreApp
