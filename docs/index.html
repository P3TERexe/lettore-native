Semplicità & Immediatezza

Come funziona sul tuo Mac

Nessuna configurazione complessa o schermata superflua. Selezioni ciò che vuoi ascoltare e continui a lavorare senza interruzioni.

Seleziona e ascolta da qualsiasi app

Non serve copiare e incollare. Evidenzia un articolo in Safari, una pagina su Apple Books, un documento Word o un PDF in Anteprima e premi una scorciatoia da tastiera: la lettura inizia all'istante.

Legge anche immagini e presentazioni

Trovato un documento scansionato, una slide o un grafico con testo non selezionabile? Cattura un riquadro dello schermo: il Mac riconosce subito le parole e te le legge ad alta voce, 100% offline.

Multilingua con oltre 20 voci neurali

Supporto nativo per 5 lingue (Italiano, Inglese, Spagnolo, Francese, Tedesco) con profili timbrici maschili e femminili calibrati. Passi da Marco a Giulia o a John in un clic, con fonetica madrelingua fluida ed espansione automatica di date, orari e abbreviazioni per ciascuna lingua.

Accessibilità Universale

Costruito per chi legge con le orecchie

Lettore è nato con un obiettivo chiaro: permettere a chi affronta affaticamento visivo, dislessia o difficoltà di concentrazione di fruire di qualunque testo sullo schermo con la stessa naturalezza di un podcast.

  • Navigazione da tastiera senza mouse: scorciatoie globali personalizzabili per avviare, mettere in pausa e scorrere i blocchi senza mai togliere le mani dalla tastiera.
  • Contrasti testati WCAG AAA: l'evidenziatore di lettura e la Dynamic Island usano colori calibrati per superare comodamente i requisiti di leggibilità sia in modalità scura che in alta luminosità.
  • Nessun furto di focus (Non-activating NSPanel): la pillola fluttuante non sottrae il focus all'editor di testo o al documento su cui stai lavorando, mantenendo intatto il tuo flusso di scrittura.
  • Rispetto delle preferenze di movimento: supporta nativamente l'opzione di sistema Reduce Motion, disabilitando oscillazioni e animazioni complesse per prevenire il disagio visivo.

Compilazione con Swift Package Manager

Clona la repository ed esegui il target nativo con un singolo comando da terminale:

Terminale macOS (Zsh) 
git clone https://github.com/P3TERexe/lettore-native.git
cd lettore-native

# 1. Avvia il backend locale in un terminale
cd backend && python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt && python main.py

# 2. In un altro terminale compila ed esegui l'app nativa
swift run LettoreApp
